Quick start

PriDroid is a launcher: it runs your own copy of Prison Architect on Android. The game itself is not included and never will be.

  1. You need to own Prison Architect on GOG. PriDroid runs the Linux version, which GOG gives you as a .sh installer.
  2. Get the game into the app. The easiest way: side menu → Sign in to GOG, then Check library and download it right on the phone. See Getting the game for the other ways.
  3. An instance is one installed copy of the game. Each has its own card on the main screen and its own settings behind the gear icon. You can keep several.
  4. Tap the play button on the card. The first launch is slower while the game prepares its files; after that it reaches the main menu in seconds.

You need Android 11 or newer, a 64-bit phone, and around 6 GB of RAM. Leave room for the game plus its converted archives — roughly twice the installer size.

If the game does not start at all, do not start changing things at random: go to Renderers and drivers and then Compatibility mode, in that order. Those two settings fix most first-run problems.

Getting the game

1. From GOG, in the app

Side menu → Sign in to GOG. You type your e-mail and password on GOG's own page — PriDroid never sees them. Then tap Check library: the app walks your account, finds Prison Architect and lists it together with any DLC you own.

Tap Download on the game. Files land in the public Download/PriDroid folder, which needs "All files access" — Android will ask, and the app cannot write there until you grant it. You can leave the app while it downloads.

When it finishes the button becomes Create an instance. Tap it and the instance screen opens with the file already chosen — and if you have downloaded DLC too, they are installed in the same step.

Signing in through Google or Facebook does not work here
A linked-account sign-in cannot complete inside an app. If that is how you normally log in to GOG, set a password first: gog.com → Sign in → Password reset. After that the in-app sign-in works.

2. From a file you already have

If you downloaded the installer on a PC, copy it to the phone and use side menu → Add game instance. PriDroid accepts the GOG .sh installer directly, and also a .zip containing one (base game plus DLC installers in a single zip works — they are unpacked into one instance).

Most file explorers refuse to hand a bare .sh to an app. If the picker does not show your file, put it in a .zip first.

3. What about Steam?

The Steam build is not supported. It refuses to run without the Steam client, and making it run outside Steam needs a layer that verifies you own the game — real work we would rather do properly than fake. It is on the roadmap. For now, use the GOG build, which is meant to run on its own.

DLC

DLC are installed into an existing instance. If you downloaded them from GOG in the app, the Install button on the DLC card takes you straight there. Otherwise: side menu → Install mod / DLC, pick the instance, choose the DLC tab, pick the file, Install.

Once installed, a DLC's features are switched on where the game expects — in the new-prison settings, under Extra settings. Gangs, for example, is a dropdown there.

Why do I have to tick a DLC again for every new prison?
The game checks whether you own a DLC by reading entitlement files, and under emulation it never reads them, so it treats everything as unowned and forgets your last choice when the new-prison window opens. The DLC itself works perfectly — you just have to pick its mode again each time you start a new prison. Prisons you have already created keep their settings.

Mods

Free Steam Workshop mods can be downloaded from inside PriDroid, without a Steam account or login: side menu → Workshop mods.

Enter the mod's ID — the number at the end of its Workshop address, …/sharedfiles/filedetails/?id=1234567890. Several IDs can be entered at once, separated by spaces. There is also a button that opens a given ID in the browser, so you can check you have the right mod before downloading it.

Downloading and installing are two steps. Each mod is saved as a .zip into the public Download/PriDroid folder, where you can see it and keep it. To put it into a game, use Install mod / DLC — there is a button on the download screen that takes you straight there — pick the instance, stay on the MODS tab, choose the zip, Install. A mod you already have as a .zip goes in the same way.

Mods are enabled in the game itself, on the Mods screen of the main menu.

Mods can change what you see in the main menu
Some mods ship their own showcase prisons. The game's main menu loads one behind the menu as a backdrop, so after installing such a mod the menu may take much longer to appear and run slowly while you are in it. That is the mod's content being simulated, not a fault in the launcher.

Renderers and drivers

Prison Architect draws with old-school OpenGL, which Android does not have. PriDroid translates it, and there are two ways to do that. If the game crashes or shows a black screen before you ever see a frame, this is the first thing to change: gear icon → Video → Renderer. It applies on the next launch.

Zink (Vulkan)

The default, and the faster of the two. It turns the game's OpenGL into Vulkan, so it needs a healthy Vulkan driver. On Adreno GPUs (Qualcomm Snapdragon) this is the proven path.

NG-GL4ES (no Vulkan)

Turns the game's OpenGL into OpenGL ES, which every Android phone has. It does not touch Vulkan at all, so it is the answer when Zink crashes — typically on Mali and other non-Adreno GPUs.

Vulkan drivers (for Zink)

With Zink you can also choose which Vulkan driver it uses: gear icon → Video → Vulkan driver. The app recommends one for your GPU. The bundled Turnip drivers are for Adreno; System means your phone's own driver. If you have a driver file of your own, side menu → Custom Vulkan driver imports it.

Changing the driver only matters for Zink. NG-GL4ES ignores it.

Picture, text size and frame rate

Prison Architect was made for a monitor, so its interface starts out very small on a phone. Two settings work together here, and using only one of them is what makes people unhappy:

  • Render resolution (gear icon → Video) — how many pixels the game draws. Lower is faster and makes everything bigger, but blurry.
  • Interface scale (gear icon) — the game's own UI size, which the game itself never lets you change. PriDroid writes it for you.

Raise both by the same factor and the interface keeps its size but gets sharper. Going from 1280×800 to 2560×1600 while moving the scale from 1× to 2× gives text the same size as before and twice the detail. Going up in resolution alone makes everything tiny; going down alone makes it blurry.

Higher resolution costs GPU time, so on a weaker phone meet in the middle — 1.5× scale at a middling resolution is often the sweet spot.

Under Frame rate you will find an on-screen FPS counter and a frame cap. Capping to 30 or 60 can make a phone run cooler and steadier than letting it race.

Controls

Touch

Tap = left click. Hold still = right click. Two fingers = pinch to zoom. Drag with one finger pans the map, if you turn that on in the settings.

On-screen controls

The buttons over the game are fully editable: gear icon → Controls → Edit controls. You can move and resize each button, change its opacity, add new ones and bind any of them to a keyboard key or a mouse action. Layouts can be exported and imported from the side menu, so you can keep one and share it.

Typing

For fields that need text — prison names, search boxes — use the on-screen keyboard button in the overlay.

Gamepad

A connected controller can be mapped to keys and mouse actions: gear icon → Controls → the gamepad button. Prison Architect has no real controller support of its own, so this is a remapping, not native gamepad play.

Saves and settings

Saves live inside the instance and stay there when you update the app. From the side menu you can export and import saves, settings and the control layout as .zip files — useful for moving to another phone or keeping a backup before you experiment.

One warning. Android deletes an app's data when it is installed with a different signing key. If you switch between builds from different sources, everything — instances and saves included — is wiped. Export first.

Compatibility mode

Gear icon → Advanced → Compatibility mode. It changes how the emulator translates the game's code into instructions your phone understands. Some devices need this to get past the loading screen at all.

It is a little slower, so leave it off while the game runs normally. Turn it on if the game will not start and changing the renderer did not help.

Getting the best performance

  • Turn on your phone's game booster and set it to its highest-performance profile. Most phones have one — Samsung Game Booster, Xiaomi/POCO Game Turbo, OPPO/OnePlus Game Space, vivo Ultra Game Mode. Make sure the profile is not "balanced" or a battery saver.
  • Keep the prison modest on a weaker phone. The cost grows with what is happening inside it: a young prison is light, a large one with hundreds of prisoners is not. This is a CPU limit, not a graphics one, so lowering the resolution will not fix a slow simulation.
  • Cap the frame rate (gear icon → Frame rate). A steady 30 often feels better than an uneven 45 and keeps the phone cooler.
  • Close background apps so the game gets the memory and CPU to itself.

Known issues

The main menu shows a prison being built by itself

That is by design. The game insists on showing a prison behind its main menu; normally it loads one of its large showcase prisons, which on a phone takes minutes and runs at a crawl. PriDroid gives it a small freshly generated map instead, so the menu appears in seconds. The side effect is that the in-game "Premade prisons" browser is empty.

DLC has to be switched on for every new prison

See DLC — the game cannot see its entitlement files under emulation. The DLC works; only the remembered default is lost.

The game crashes before showing anything

Try the other renderer first, then Compatibility mode. If neither helps, send a report — a crash this early is usually something we can name exactly from the log.

Old game versions

PriDroid is developed against the current GOG build. Much older builds carry bugs that were fixed in the game years ago and can behave differently. If your copy is years old, updating it in GOG is worth trying before anything else.

Reporting a problem

Side menu → Report a Bug. It collects the launcher log, the emulator log, the game's own log, your settings and the system's record of how the app exited, and packs them into a .zip you can attach to an e-mail.

What makes a report useful:

  • Send it right after the problem happens, before launching again — the logs only keep the most recent runs.
  • Change one thing at a time. If you turn on three settings at once and it works, nobody learns which one mattered.
  • Say what you did and what you expected. "Black screen after tapping play, sound was working" is worth more than a zip on its own.
  • Turn on Debug (gear icon → Advanced) before reproducing a launch problem. It adds detail to the logs and changes nothing else.

Reports from devices we do not own are the only way this gets better. Development happens on two phones; everything we know about the rest comes from you.
